Petroglyphs

=================



A collection of petroglyph notes with their pictures in Markdown format, made for importing in Obsidian.

\--------------------



```text

├── 📄 README.md
└── 📄 desktop.ini

```



File format

\-----------



Each petroglyph file can follow this general structure:



```text

Basic information



Name:

Location:

Date/period:

Object type:


Notes



Sources

```
